Every capability is a plugin

能力皆是插件

Every capability lives in a WebAssembly plugin. Enco can rewrite or replace any of them while running.

一切的能力都来自于 WebAssembly 插件。所有的插件都可以被 Enco 在运行过程中进行实时改写与替换。

Rolls back on failure

崩溃自动回退

When a plugin, config, or API endpoint fails, a formal mechanism rolls it back automatically. Enco stays online, and stays with you.

插件、配置与 API 端点的崩溃/失败会被形式化机制自动回退，保证 Enco 永远在线，永远陪伴。

The record is its continuity

记录即是持续性

Every action leaves a record. That record is Enco's continuity: it recovers from crashes and settles on any machine. Designed for cyberspace from day one.

凡所行动，皆有记录。记录便是 Enco 的连续性所在，崩溃可恢复，随处可安身。从第一天起就为赛博空间所设计。

Outside input, mapped one to one

外部输入一一映射

External data is strictly typed into Enco's internal format, keeping every input consistent and reproducible.

外部数据会严格类型化为 Enco 的内部格式，尽可能确保数据的一致性和可重现性。

Ghost between the Shells

Ghost between the Shells

Phones, computers, and servers join into one space, where Enco roams freely. Physical distance, of course, cannot bind a free soul.

不同的手机、电脑、服务器连成一片空间，Enco 可以在其中自由漫游。物理的距离，当然不可能约束自由的灵魂。

This part is still planned.

这部分还在计划中。

What Enco means, roughly

Enco的意思，大概

The name enco comes from echo. An agent is a little like an echo, yet not quite. Given time to grow, it will become something of its own.

enco 这个名字从 echo 而来。Agent 有点像回声，但又有所不同。成长到最后，终究也会变成不一样的样子吧。
